PHẦN 1: LỰA CHỌN MÔ HÌNH AI PHÙ HỢP
================================================================================

VẤN ĐỀ CỤ THỂ:
  - Input : Ảnh waterfall 640×640 px, màu cầu vồng
  - Trục X: tần số (100 MHz span)
  - Trục Y: thời gian (~21 giây tại 30 FPS)
  - Mục tiêu: phân biệt UAV (DJI, Skydio...) vs nhiễu nền

ĐẶC ĐIỂM TÍN HIỆU UAV TRÊN WATERFALL:
  ┌─────────────────────────────────────────────────────────┐
  │ FHSS (Frequency Hopping): xuất hiện ngắt quãng, nhiều  │
  │   dải tần, pattern đặc trưng của từng hãng             │
  │ OFDM (DJI Lightbridge/OcuSync): băng thông 10-20 MHz,  │
  │   liên tục, chiếm cố định một dải tần                  │
  │ 2.4 GHz + 5.8 GHz: thường dùng đồng thời              │
  └─────────────────────────────────────────────────────────┘

KHUYẾN NGHỊ MÔ HÌNH:
  ┌─────────────────────────────────────────────────────────────────────────┐
  │ STAGE 1: PHÁT HIỆN (Detection)                                          │
  │                                                                         │
  │ ▶ YOLOv11n (KHUYẾN NGHỊ NHẤT)                                          │
  │   + Mới nhất (2024), nhỏ nhất, nhanh nhất                              │
  │   + ~2.6M params, ~3ms/inference GPU                                   │
  │   + Bounding box → biết chính xác tín hiệu UAV ở đâu trong waterfall   │
  │   Cài: pip install ultralytics                                          │
  │                                                                         │
  │   YOLOv8s (thay thế nếu cần)                                           │
  │   + ~11M params, chính xác hơn v11n một chút                           │
  │   + ~5ms/inference GPU                                                  │
  │                                                                         │
  │ STAGE 2: PHÂN LOẠI CHỦNG LOẠI (Classification)                         │
  │                                                                         │
  │ ▶ EfficientNetV2-S (KHUYẾN NGHỊ NHẤT)                                  │
  │   + ~21M params, ~8ms/inference CPU                                    │
  │   + Chính xác cao, pretrained ImageNet → transfer learning tốt          │
  │   + Deploy được trên CPU (không cần GPU khi inference)                 │
  │   Cài: pip install timm                                                 │
  │                                                                         │
  │   Swin Transformer-T (thay thế nếu dataset lớn >10K ảnh)               │
  │   + Self-attention nắm pattern tần số-thời gian tốt hơn CNN             │
  │   + ~28M params, cần nhiều data hơn để train hiệu quả                  │
  │   + Chính xác tốt hơn EfficientNet khi có đủ data                      │
  └─────────────────────────────────────────────────────────────────────────┘

TẠI SAO KHÔNG DÙNG ResNet THUẦN:
  ResNet-50 kém hơn EfficientNetV2-S ~3% accuracy với cùng kích thước
  EfficientNetV2-S nhanh hơn 30% và chính xác hơn

TẠI SAO KHÔNG DÙNG ViT NGAY:
  ViT cần >50K ảnh để train tốt. Dataset ban đầu thường <5K ảnh.
  EfficientNetV2-S hiệu quả hơn với dataset nhỏ nhờ inductive bias CNN.

PHẦN 2: THU ẢNH WATERFALL (TẠO DATASET)
================================================================================

2.1 CẤU HÌNH TRƯỚC KHI THU
───────────────────────────
Trên giao diện phần mềm:

  a) Ref Level: -20 dBm (phù hợp với UAV ở tầm 100-500m)
     → Nếu tín hiệu quá yếu: chọn -30 hoặc -40 dBm

  b) Dynamic Range: 80 dB (nền navy đến đỉnh đỏ = 80 dB)

  c) Scale to Ref: BẬT (thang màu tự động theo ref/dyn_range)
     → Đảm bảo tất cả ảnh cùng thang màu → model học nhất quán

  d) Các kênh tần số: thêm tần số bay của UAV bạn cần nhận diện
     Thông dụng: 2400 MHz ±50 MHz (2.4 GHz), 5800 MHz ±50 MHz (5.8 GHz)
     DJI OcuSync 3: cũng hoạt động ở 900 MHz

  e) Hold time: 1-2 giây mỗi kênh

2.2 THU ẢNH THỦ CÔNG 📷 (cho dataset có nhãn chính xác)
─────────────────────────────────────────────────────────
  - Nhấn nút 📷 trên slot khi UAV đang hoạt động
  - Ảnh được lưu vào captures/ với kết quả AI tự động
  - Sau đó gán nhãn thủ công qua API:

    curl -X PUT "http://localhost:8000/api/captures/1/label?label=DJI_Mini_2"

  - Hoặc gán hàng loạt bằng script:

    python << 'PY'
    import requests
    rows = requests.get("http://localhost:8000/api/captures").json()
    for c in rows["captures"]:
        requests.put(f"http://localhost:8000/api/captures/{c['id']}/label",
                     params={"label": "uav", "notes": "DJI Mini 2, 100m"})
    PY

2.3 THU ẢNH TỰ ĐỘNG 🔴 (cho dataset số lượng lớn)
───────────────────────────────────────────────────
  - Nhấn nút 🔴 trên slot → dialog cấu hình
  - Nhập thư mục lưu, ví dụ:
      D:\dataset\uav\DJI_Mini2\    (khi có UAV đang bay)
      D:\dataset\no_uav\noise\     (khi không có UAV)

  - Nhấn "▶ Bắt đầu thu" → ảnh tự động lưu sau mỗi lần chuyển kênh
  - Thanh đỏ "● THU TỰ ĐỘNG" hiện số ảnh đã thu

  QUAN TRỌNG: Tổ chức ảnh theo folder ngay từ đầu:
    dataset_raw/
    ├── uav/
    │   ├── DJI_Mini2/      ← thu khi DJI Mini 2 đang bay
    │   ├── DJI_Phantom4/   ← thu khi DJI Phantom 4 đang bay
    │   └── controller/     ← thu khi tay cầm đang kết nối
    └── no_uav/
        ├── background/     ← môi trường sạch không có UAV
        └── interference/   ← nhiễu WiFi, Bluetooth (negative hard samples)

2.4 SỐ LƯỢNG ẢNH CẦN THIẾT
────────────────────────────
  Tối thiểu (classify hoạt động):
    500 ảnh/lớp × 2 lớp = 1000 ảnh

  Tốt (kết quả ổn định):
    2000 ảnh/lớp × số lớp

  Lý tưởng (chính xác cao):
    5000+ ảnh/lớp × số lớp

  Với 2 kênh × hold 1s × 30 FPS = 30 ảnh/phút/kênh
  Chạy 30 phút = ~900 ảnh/kênh

2.5 ĐIỀU KIỆN THU ĐA DẠNG
───────────────────────────
  Thu trong nhiều điều kiện để model không overfit:
    ✓ Khoảng cách khác nhau: 50m, 100m, 200m, 500m
    ✓ Hướng bay khác nhau: bay thẳng, hover, maneuver
    ✓ Nhiều UAV cùng lúc (nếu có thể)
    ✓ Nhiễu nền khác nhau: WiFi, Bluetooth, radar khí tượng
    ✓ Thời điểm khác nhau: sáng/chiều (nhiệt độ ảnh hưởng noise floor)
    ✓ Chế độ video, ảnh, hover, sport mode của UAV

4.3 TRAIN YOLO (phát hiện bounding box)
─────────────────────────────────────────
  Cần annotation YOLO format (.txt) trước:
    Mỗi file .txt cùng tên với ảnh .png:
    Nội dung: <class_id> <x_center> <y_center> <width> <height>
    (tất cả normalized 0.0-1.0)

    Ví dụ file label: 20240101_uav.txt
    0 0.35 0.42 0.28 0.15    ← class 0 (uav_signal), bbox

  Tool annotation khuyến nghị:
    - Label Studio (web): https://labelstud.io
    - Roboflow (online): https://roboflow.com
    - CVAT (self-hosted): https://cvat.ai

  Sau khi có annotation:
  python step2_train.py \
    --mode    yolo \
    --data    yolo_dataset \
    --epochs  100 \
    --batch   16 \
    --out     yolo_output

PHẦN 6: ĐÁNH GIÁ & ĐIỀU CHỈNH
================================================================================

6.1 KHI MODEL KHÔNG CHÍNH XÁC
───────────────────────────────
  Accuracy thấp (<80%):
    → Thu thêm ảnh (ít nhất 2000/lớp)
    → Kiểm tra dataset cân bằng (equal samples per class)
    → Tăng epochs lên 100-200

  Overfitting (train_acc >> val_acc):
    → Thu thêm ảnh đa dạng hơn
    → Tăng dropout: sửa model.drop_rate trong step2_train.py
    → Thêm augmentation mạnh hơn

  Underfitting (cả train và val thấp):
    → Tăng số epochs
    → Giảm learning rate: lr=5e-5 thay vì 1e-4
    → Dùng model lớn hơn: efficientnetv2_m
